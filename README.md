# Сайт «ТСК — туристские спортивные комплексы»

ООО «Современные технологии спорта». Сайт: https://tsk-st.ru

- `index.html` — оформление и код сайта (инженерный стиль). Содержимое подставляется при публикации из `content/site.json`.
- `content/site.json` — каталог, фотоальбом, фото на главной, новости. Его меняет панель управления.
- `photos/`, `images/` — фотографии и схемы.
- `admin/` — панель управления (https://tsk-st.ru/admin/), см. `ИНСТРУКЦИЯ.md`.
- `scripts/build.mjs` — сборка: подстановка данных, зимний вариант `/winter/`, проверка картинок.
- `.github/workflows/pages.yml` — публикация на GitHub Pages; шрифты и three.js скачиваются в `vendor/`, без зарубежных CDN.
