# Сайт ООО «Современные технологии спорта»

Туристские спортивные комплексы ТСК: каталог с 3D-моделями, фотоальбом, информация о компании.

- `index.html` — основной сайт в инженерном стиле.
- `winter/index.html` — запасной вариант в зимнем оформлении.
- `eng/index.html` — перенаправление со старого адреса на главную.
- `.github/workflows/pages.yml` — публикация на GitHub Pages. При публикации шрифты и библиотека three.js скачиваются и кладутся рядом с сайтом, поэтому страница не обращается к зарубежным CDN.

Сайт публикуется автоматически после каждого изменения в ветке `main`.
