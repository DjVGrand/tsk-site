# Панель управления сайтом tsk-st.ru

Адрес: **https://tsk-st.ru/admin/** — работает на компьютере и на телефоне.

## Что можно менять
- **Фотоальбом** — добавлять фото (сжимаются автоматически), подписи, порядок (перетаскиванием или стрелками), удалять. Звёздочка ★ — показать фото на главной.
- **Главная** — какие фото (до 5) показаны в блоке «Комплексы в работе» и в каком порядке; первое — крупное.
- **Каталог** — конструкции: название, описание, этапы, варианты (длина, ширина, нитки, назначение), схемы, фото, тип 3D-модели; добавить или удалить конструкцию.
- **Новости** — дата, заголовок, текст, фото. Три последние новости появляются и на главной.

Изменения копятся в панели и попадают на сайт только после кнопки **«Опубликовать»**. Сайт обновляется через 1–2 минуты; статус виден в панели. Если в данных ошибка, сборка не пройдёт и сайт останется прежним.

## Доступ
**Сотрудники входят по общему паролю** — аккаунт GitHub им не нужен. При входе панель спрашивает имя, оно попадает в историю изменений.

**Первая настройка (один раз, владелец):**
1. Создайте ключ доступа: github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token. Repository access: Only select repositories → `tsk-site`. Permissions: **Contents — Read and write**, **Actions — Read-only**. Срок действия — до года.
2. Откройте https://tsk-st.ru/admin/ → «Войти по ключу GitHub» → вставьте ключ.
3. Нажмите **«Доступ»** вверху панели и задайте пароль (не короче 14 символов, лучше 4–5 случайных слов). Через 1–2 минуты вход по паролю заработает.

Ключ хранится на сайте только в зашифрованном паролем виде.

**Если сотрудник уходит или пароль мог попасть к посторонним:** создайте новый ключ, удалите старый в GitHub и в окне «Доступ» задайте новый пароль вместе с новым ключом.

**Раз в год**, когда истекает срок ключа: создайте новый ключ и введите его в окне «Доступ» вместе с паролем (можно тем же).

Каждая публикация — отдельная запись в истории: https://github.com/DjVGrand/tsk-site/commits/main (видно, кто и что менял). Любое изменение можно откатить — попросите Claude.
