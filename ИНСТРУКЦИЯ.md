# Панель управления сайтом tsk-st.ru

Адрес: **https://tsk-st.ru/admin/** — работает на компьютере и на телефоне.

## Что можно менять
- **Фотоальбом** — добавлять фото (сжимаются автоматически), подписи, порядок (перетаскиванием или стрелками), удалять. Звёздочка ★ — показать фото на главной.
- **Главная** — какие фото (до 5) показаны в блоке «Комплексы в работе» и в каком порядке; первое — крупное.
- **Каталог** — конструкции: название, описание, этапы, варианты (длина, ширина, нитки, назначение), схемы, фото, тип 3D-модели; добавить или удалить конструкцию.
- **Новости** — дата, заголовок, текст, фото. Три последние новости появляются и на главной.

Изменения копятся в панели и попадают на сайт только после кнопки **«Опубликовать»**. Сайт обновляется через 1–2 минуты; статус виден в панели. Если в данных ошибка, сборка не пройдёт и сайт останется прежним.

## Доступ
Для входа нужен **ключ доступа GitHub**.

**Владелец (DjVGrand):** github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
Repository access: Only select repositories → `tsk-site`. Permissions: **Contents — Read and write**, **Actions — Read-only**.

**Сотрудник:**
1. Регистрируется на github.com.
2. Владелец добавляет его: репозиторий `tsk-site` → Settings → Collaborators → Add people. Сотрудник принимает приглашение из письма.
3. Сотрудник создаёт ключ: Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token, отмечает только **public_repo**, задаёт срок действия.

Ключ показывается один раз. Не пересылайте его в мессенджерах. Если сотрудник уходит — владелец удаляет его из Collaborators, и его ключ перестаёт работать для сайта.

## История и откат
Каждая публикация — отдельная запись в истории: https://github.com/DjVGrand/tsk-site/commits/main (видно, кто и что менял). Любое изменение можно откатить — попросите Claude.
